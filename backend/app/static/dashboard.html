Cross-Platform Project Status Dashboard with AI Insights

A local AI watches your GLPI tickets and OpenProject tasks and turns them into clear, readable project insights.

How it works: Each button asks the locally hosted AI model (llama.cpp) to look at your live data and write something for you. Clicking a button gathers the current ticket / task data, sends it to the model, and shows the result below. Each task can take up to a minute.

  • Summary: Split into OPS Side (IT tickets as a table + summary) and DEV Side (development tasks as a table + summary).
  • Incident Analysis: Reads the actual tickets and focuses on analysis on what's recurring, common issues, and what to investigate first.
  • Report: The full structured status report (Project Status / IT Support / Development / Risks).
